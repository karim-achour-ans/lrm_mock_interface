    Ouvrir le simulateur ↗
    Activer le dépôt automatique (installation unique)

    Le simulateur n'accepte que les envois faits depuis ses propres pages. Un petit script installé dans votre navigateur s'en charge : au clic sur « Lancer une recherche », le Bundle est déposé en arrière-plan, puis la recherche SAS s'ouvre.

    1. Installez l'extension Tampermonkey.
    2. Installez le script, puis rechargez cette page.

    Sans le script, la recherche s'ouvre sans dépôt et un bouton « Ouvrir le simulateur avec le Bundle » apparaît. Le Bundle est alors copié dans le presse-papiers : collez-le dans « JSON Data », ou cliquez sur le favori SAS → simulateur (à glisser dans la barre de favoris) pour remplir et soumettre le formulaire.
